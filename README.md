Program -> finetuning_Src_Tgt.py implements an optimized pipeline to fine-tune the facebook/nllb-200-distilled-600M model for translation across Dravidian languages. It streams custom parallel text files for training, dynamically matches evaluation benchmarks, and applies tokenization using modern sequence-to-sequence standards before saving the finalized model locally. To prevent out-of-memory errors on limited hardware, the code integrates advanced VRAM savings like 8-bit AdamW optimization (adamw_bnb_8bit), gradient checkpointing, and gradient accumulation.
