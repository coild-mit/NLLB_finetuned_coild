Program -> finetuning_Src_Tgt.py implements an optimized pipeline to fine-tune the facebook/nllb-200-distilled-600M model for translation across Dravidian languages. It streams custom parallel text files for training, dynamically matches evaluation benchmarks, and applies tokenization using modern sequence-to-sequence standards before saving the finalized model locally. To prevent out-of-memory errors on limited hardware, the code integrates advanced VRAM savings like 8-bit AdamW optimization (adamw_bnb_8bit), gradient checkpointing, and gradient accumulation. Hugging Face Authentication: To provide your required Hugging Face token, either run huggingface-cli login in your terminal before execution (recommended) or paste your actual access token directly into the script by replacing the "HF_TOKEN" placeholder on line 15 (e.g., HF_TOKEN = "hf_xXyYzZ...").


Program -> testing_Src_Tgt.py evaluates a fine-tuned NLLB-200 translation model across Dravidian language pairs by running batched inference on a benchmark test set. It automatically calculates five key performance metrics: SacreBLEU, chrF++, TER, METEOR, and ROUGE-L to gauge translation quality. The final metrics and raw text comparisons are structurally exported into both Excel spreadsheets and .txt files for analysis.
